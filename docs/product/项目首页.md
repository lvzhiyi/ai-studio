# ai-studio · AI 短剧 Agent 工作台

编排多步骤、多模态、长耗时任务的 Agent 工作台，以 AI 短剧制作为验证场景：输入故事，由 Agent 走完拆分镜、检查、出图、质检、重画、配音、合成预览视频，关键步骤由人确认。

## 协作约定

- 开发流程入口是 ai-dev-workflow 的 `workflow-core:workflow` 技能。项目配置见根目录 `ai-workflow.yaml`，项目术语见[术语表](术语表.md)。
- 同一事实只维护一处：业务规则归需求说明，产品状态归模块卡，技术方案归 `docs/superpowers/specs`。
