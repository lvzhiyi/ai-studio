# UI 规范

## 设计来源

- 项目没有设计工具和设计稿，界面规则以本文件和 `web/src/styles.css` 为准。

## 主题与样式入口

- 主题/样式入口：`web/src/styles.css`（深色主题，`:root` 下的 CSS 变量），共用组件在 `web/src/components/ui.tsx`。
- 原则：内容（图、视频）是主角，界面退后；状态色（`--good`、`--warning`、`--critical`）只用于状态，并且总是配图标或文字。

## 色彩、字体、间距

- 色彩与字体：见 `web/src/styles.css` 的 `:root` 变量，不在页面里写死颜色。
- 间距：待确认

## 状态与适配

- 普通、聚焦、错误、禁用、加载状态分别核对；未接入的操作不给出“成功”反馈。
- 适配：待确认
